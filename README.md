# Mifugo Prototype: test builds

Download the latest test APK from **[Releases](https://github.com/MichaelKitticai/mifugo-prototype-release/releases/latest)**.

It's a test app of the Mifugo Wallet redesign. It installs **next to** the real
Mifugo Wallet (it won't replace it) and never sends anything to the server.
Once installed it updates itself: when a new build is out, the app shows
**Update available**.

`latest.json` is the update feed the app reads. Don't edit it by hand.
